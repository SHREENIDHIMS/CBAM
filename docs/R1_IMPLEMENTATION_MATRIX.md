# R1 Pilot and R1 Live implementation matrix

Baseline: local `main` at `9e1173b` on 27 October 2026. Remote `origin/main` was
`c8089b5`; local `main` also contained the locally merged, unmerged-remote work from
PRs #18, #19, #20 and #21. This matrix records executable evidence, not checklist
intent. Synthetic HMRC fixtures are not evidence of compatibility with a masked real
report. Reference data that is draft, fixture-only or pending cannot drive a legal
decision.

Status terms: **verified** means the implemented slice has executable evidence;
**awaiting external verification** means the technical slice works but required real
data, approval or legal evidence is absent; **partial** means a material acceptance
criterion or layer is missing; **not started** means no requirement-specific workflow
exists. The repository currently has no `backend/tests/security/` directory, despite
`docs/TESTING.md` naming it as a release gate.

## Baseline verification evidence

- Backend static gates: Ruff check, Ruff format check and mypy passed on 27 October 2026.
- Backend without database: 387 passed, 423 skipped. This is not a release result.
- Backend on isolated local `cbam_test`: 799 passed, 11 skipped in 724.13 seconds;
  the focused migration suite also passed 9/9. The remaining skip reasons require
  release-evidence review; they are not silently counted as passes.
- Frontend lint and typecheck passed; 12 Vitest files / 137 tests passed serially;
  production build passed.
- Targeted imports and coverage Playwright/axe run: 9 passed after the sidebar
  contrast correction. PR #21 has green backend, frontend and secret-scan jobs.
- Full local Playwright run: 16 passed and one coverage-register assertion timed out
  under four workers; the complete coverage file then passed 3/3 with one worker.
  PR #21's frontend CI (including the full Playwright command) passed. Treat the local
  parallel timeout as a reliability item until it is reproduced or eliminated.
- A documentation/CI mismatch is open: `docs/TESTING.md` requires
  `backend/tests/security/`, but that directory is absent and the checked-in CI runs
  only unit, scenario and integration folders.

## Release position at this baseline

- **R1 Pilot: not ready.** Scope, tax point, threshold, supplier portal, outreach,
  evidence, dashboard and several required security journeys are not complete. Real
  masked HMRC report compatibility and regulatory-data approval remain external gates.
- **R1 Live: not ready.** Registration, exports, resilience/restore, forecasts,
  currency provenance, shared installations, privileged access and the source watcher
  are not complete.
